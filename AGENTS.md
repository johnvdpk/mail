# AGENTS

Zie `CLAUDE.md` voor de codestandaarden en projectconventies van dit project — die gelden onverkort voor elke agent die hier werkt, inclusief het nachtelijke ticket-systeem (`scripts/run-tickets.sh`).

Kort: `npm run lint`, `npm test`, `npx tsc --noEmit` en `npx next build` moeten allemaal slagen voordat werk als klaar geldt.
